# Changelog

Notable changes to the Sokoni storefront.

## [1.0.0] — 2026-08-10

### Added
- Product catalogue with search, category filtering and sorting
- Product detail dialog
- Cart persisted in localStorage with stock-aware quantity controls
- Delivery pricing with a free-delivery threshold
- Checkout with field validation and order confirmation
- Responsive layout and reduced-motion support

### Deployment
- Published to GitHub Pages from the repository root
