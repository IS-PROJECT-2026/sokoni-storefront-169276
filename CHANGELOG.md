# Changelog

Notable changes to the Sokoni storefront, in Keep a Changelog format and
grouped by the milestone that delivered them.

## [1.1.0] - 2026-08-14

### Changed
- Real product photos instead of inline SVG icons
- New look: paper background, serif headings, thin rules
- Plainer wording across the pages

### Fixed
- Cart badge no longer shows 0 on an empty cart
- Clear cart button hidden when there is nothing to clear

## [1.0.0] - 2026-08-10

### M3: Discovery, Polish and Release
- Search across product name, description and category
- Category filtering and five sort orders
- Responsive layout down to 320px
- Reduced-motion support

### M2: Cart and Checkout
- Cart persisted in localStorage
- Quantity controls clamped to available stock
- Free delivery over KES 20,000
- Checkout with field validation and order confirmation

### M1: Catalogue Foundation
- Design token layer and page chrome
- Product catalogue data module
- Responsive product grid
- Product detail dialog

### Deployment
- Published to GitHub Pages from the repository root
